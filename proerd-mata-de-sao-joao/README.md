# Abertura Cinematográfica — PROERD Mata de São João

Abertura institucional em 16:9, criada como uma experiência web cinematográfica para apresentação do PROERD em Mata de São João – Bahia.

## Como usar
Abra `index.html` em um navegador em tela cheia. Cada cena avança automaticamente a cada 4,2 segundos. Um clique também avança para a próxima cena.

## Direção visual
- Azul-marinho escuro
- Iluminação dramática e partículas
- Movimentos lentos/elegantes
- Números em dourado
- Destaques em branco e vermelho
- Estética institucional premium, sem aparência infantil ou de PowerPoint

## Texto
Os textos e números foram mantidos exatamente conforme o briefing.
